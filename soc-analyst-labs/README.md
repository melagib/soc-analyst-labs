# SOC Analyst Labs

A learning portfolio for Mohamed Ibrahim Elagib, focused on security monitoring, log analysis, and clear investigation reports.

## Start here

**[Lab 01: Investigate suspicious login activity](labs/01-login-investigation/README.md)**

Work through a small, fictional authentication dataset, identify activity worth investigating, and document your reasoning. Read the exercise in GitHub first; run the analyzer when Python is available.

## Designed for a modest laptop

- Python 3 standard library only: no paid tools, additional packages, or virtual machines.
- Small text files that can be opened in Notepad or viewed directly in GitHub.
- No connection to remote systems and no attack traffic generated.

## Repository guide

| Path | Purpose |
| --- | --- |
| `labs/01-login-investigation/` | Instructions, synthetic logs, and report template |
| `tools/analyze_logins.py` | A small authentication-log analyzer |
| `tests/test_analyze_logins.py` | Checks for detection logic and invalid input |

## Publishing evidence

Use the supplied synthetic data. Keep real credentials, personal information, employer logs, and private incident details out of this public repository. Future exercises should use systems you own or have permission to investigate.
